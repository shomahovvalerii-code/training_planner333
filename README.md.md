# Currency Converter (Конвертер валют)

**Автор:** Елена Соколова

## Описание

Приложение «Currency Converter» предоставляет простой и удобный способ конвертировать валюты в реальном времени с использованием надёжного API. Интерфейс на базе `tkinter` позволяет выбрать исходную и целевую валюту, ввести сумму, мгновенно получить результат и отслеживать историю всех конвертаций. Данные истории сохраняются локально в формате JSON.

## Функциональные возможности

- 💱 Конвертация между 24 популярными мировыми валютами
- 🌐 Получение актуальных курсов через [exchangerate-api.com](https://www.exchangerate-api.com/)
- 📜 Просмотр истории конвертаций в удобной таблице
- 💾 Сохранение истории в `history.json` и автоматическая загрузка при старте
- 📤 Экспорт истории в текстовый файл
- 🛡️ Валидация ввода (сумма должна быть положительным числом)
- 🧹 Очистка истории
- ⚡ Обработка сетевых ошибок и ошибок API

## Требования

- Python 3.6+
- Установленная библиотека `requests` (для HTTP-запросов)
- API-ключ от [exchangerate-api.com](https://www.exchangerate-api.com/) (бесплатный план)
